# TripleTen - Around The U.S.

## Descripción

Este proyecto consiste en una página web interactiva donde los usuarios pueden editar la información de su perfil y administrar una colección de fotografías.

En esta etapa del proyecto se implementó la funcionalidad para:

- Editar el nombre y la descripción del perfil.
- Abrir y cerrar ventanas emergentes (modales).
- Agregar nuevas tarjetas.
- Dar "Me gusta" a las tarjetas.
- Eliminar tarjetas.
- Visualizar imágenes en un modal.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Metodología BEM
- Git
- GitHub
