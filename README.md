# TripleTen - Around The U.S.

## Descripción

Around The U.S. es una aplicación web interactiva que permite a los usuarios gestionar su perfil y compartir fotografías mediante tarjetas.

El proyecto fue desarrollado como parte del programa de Desarrollo Web de TripleTen.

En el Sprint 12 se implementó la integración con una API REST, permitiendo almacenar y recuperar información desde un servidor.

## Funcionalidades

- Visualizar la información del perfil del usuario.
- Editar el nombre y la descripción del perfil.
- Actualizar la fotografía de perfil.
- Agregar nuevas tarjetas con imágenes y títulos.
- Dar y quitar "Me gusta" a las tarjetas.
- Eliminar las tarjetas creadas por el usuario.
- Confirmar la eliminación mediante una ventana emergente.
- Visualizar imágenes ampliadas en una ventana modal.
- Validar los formularios antes de enviarlos.
- Cerrar ventanas emergentes mediante el botón de cierre, la tecla Escape o un clic fuera de su contenido.
- Mostrar indicadores de carga durante las solicitudes al servidor.
- Conservar los cambios después de recargar la página gracias a la integración con la API.

## Estructura del proyecto

El código fuente se encuentra organizado en la carpeta `src/`:

- `blocks/`: estilos CSS de los componentes.
- `components/`: clases JavaScript.
- `images/`: imágenes e iconos.
- `page/`: archivos principales de CSS y JavaScript.
- `vendor/`: fuentes y estilos externos.
- `index.html`: estructura HTML de la aplicación.

## Ejecución local

1. Clonar el repositorio.
2. Abrir el proyecto en Visual Studio Code.
3. Ejecutar `src/index.html` mediante Live Server.
